FAQ

Good to know.

Is this store for Android only?

Yes. This version is intentionally for the supplied E.D.I.T.H. Android assistant. Windows and iOS products are not included.

Can I keep uploading new APK versions?

Yes. The admin release manager is designed so you can publish a new APK, version code, release notes and price. The newest published release becomes the public current release while older releases are archived.

Can a customer use one license on another phone?

Not by default. The activation system binds a license to the first approved installation. You, as admin, can revoke/reset a device when a legitimate replacement is needed.

Will the APK be impossible to decompile?

No Android APK can honestly be guaranteed impossible to reverse engineer. The production build should use obfuscation, signing checks, tamper detection and server-side license enforcement to make unauthorized modification substantially harder.

Do I need a paid server to start?

The starter is designed around Cloudflare's free allowances. Static assets are free and Workers/D1/R2 have included free usage, but limits apply and costs can occur if usage exceeds them.
